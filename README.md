# Dio, AI and Light

Personal website of Dionisius Felysto Bagastama (Dio), Informatics student at Telkom University working on neural networks for photonic sensing.

Live site: https://dionisiusfb.github.io/Personal-website/

## What's inside

- `index.html`: the whole site (HTML, CSS and JavaScript in one file, no build step)
- `img/`: photos
- `fonts/`: Unbounded and Atkinson Hyperlegible, self-hosted under the SIL Open Font License
- `cv/`: public CV (PDF)

## Features

- Three ways in: a 30-second version for recruiters, the full story, and "the diagonal"
- Piko, a scripted guide who flies to each section, with an optional "bip" voice
- English and Indonesian, day and night mode, recruiter mode, and an animations switch
- An interactive demo of the hybrid readout from my ICICyTA 2026 paper

To run it locally, open `index.html` through any static file server, for example `python -m http.server`.
